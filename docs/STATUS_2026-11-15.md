## Verification performed

Core tests cover DCT inversion/DC scale; zigzag and RLE edge cases; arithmetic
coding including probability rescaling; known translation/sign convention;
grayscale/RGB, arbitrary dimensions and GOP transitions; exact encoder/decoder
agreement; all supported block sizes; skip behavior; static-scene bitrate
savings; corruption/truncation and resource limits; invalid settings; metric
values; and analytically known BD-Rate offsets. The command is:

```powershell
python -m unittest discover -s tests -v
```

The bundled Python runtime was used for verification. The system `python` alias
was not usable in this environment. NumPy and Pillow were available. OpenCV was
not available, so actual MP4 input is explicitly not yet verified.

## Initial deterministic smoke experiment

12 grayscale frames, 80x64 pixels, 30 FPS; 16x16 prediction blocks, 8x8 DCT,
radius 4, GOP 12, skip enabled. These are measured outputs, not assumed results.

| Quantizer step | Intra bytes | Hybrid bytes | Intra PSNR dB | Hybrid PSNR dB |
| --- | ---: | ---: | ---: | ---: |
| 8 | 20,854 | 6,629 | 41.00 | 41.03 |
| 16 | 10,016 | 3,439 | 35.71 | 35.70 |
| 32 | 3,208 | 1,237 | 33.46 | 33.52 |
| 64 | 2,128 | 860 | 31.90 | 32.21 |

Classical cubic BD-Rate: -66.10% on the shared PSNR interval for this synthetic
clip only. All eight decoded sequences matched encoder reconstruction exactly.
Raw measurements and bitstreams are in `output/evaluation/`.

## Next experiments

1. Select at least three clips covering low motion, camera motion, and complex
   object motion/scene changes. Record source, frame range, resolution and FPS.
2. Compare intra and hybrid with identical inputs and four or more qsteps;
   inspect quality and RD curves, ensuring shared PSNR ranges.
3. Compare skip on/off; separately compare search radii 2, 4, and 8. Report
   measured encoding time as well as bitrate and distortion.
4. Review RGB versus luma-only scope with the team. Add YUV 4:2:0 only if required.
5. Profile before implementing hierarchical/fast search. Exhaustive search cost
   grows roughly with `(2*radius+1)^2`; small clips are intentional for now.
6. Use measured results to write the final report, including blocking artifacts,
   memory/runtime limits, cubic BD-Rate limitations and scope exclusions.
